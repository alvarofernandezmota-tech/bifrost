# Cierre — bifrost pasa a legado

Desde el ADR-024 (fases 5-6, ejecutadas en `hugin`), el bot de Telegram en
producción corre como `hugin-telegram` desde `producto-bot/telegram`,
usando `hugin.personal` y `hugin.mente/negocio/guardado`.

`bifrost.service` queda instalado y parado en Madre, solo como vuelta
atrás. Este repo no recibe más features: los fixes de código real van
a `hugin`. La descripción de GitHub de este repo hay que corregirla,
ya no dice la verdad ("En producción").
